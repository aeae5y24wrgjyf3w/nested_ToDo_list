# ツリー状のToDoリスト
タスクまたはその進捗をツリー状に管理する。

## 環境
ブラウザ(Edgeで検証済み)

## 機能
ツリーの各ノードには以下の操作ができる。
- 子ノードの追加(その際文字列を打つ必要がある。)
- ステータス(Open/Closed)の切り替え

ツリーはネストされたリストとして表示される。最も新しいノードを含むサブツリーから順に上から表示される。

ステータスがClosedのノードは表示されなくなる。ただしステータスがClosedであっても、配下にOpenのノードがあれば表示される。

ツリーはJSONファイルとして出力することができ、また取り込むことができる。
